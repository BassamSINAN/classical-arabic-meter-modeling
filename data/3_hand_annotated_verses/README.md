# 3. Hand-annotated verses

Verses annotated by hand by the author of the thesis: for each verse, the
*taqṭīʿ* (scansion) and the *baḥr*, checked manually.

## Why

The meter labels of the corpora can be wrong. These verses are the reference
used to evaluate the scansion algorithm `f`: its output is compared with the
hand annotation, not with the corpus label.
